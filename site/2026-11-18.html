02Anthropic выходит на биржу: Amazon и Google вместе получат почти 30%

techcrunch.com4 источникаанонстакже: The Guardian, Techmeme, Bloomberg

Почему важноЗначит, у Anthropic появятся публичные отчёты, а её крупнейшие владельцы станут видны всем.

После IPO Amazon будет владеть чуть меньше 15% Anthropic с опцией выкупить больше, а у Google почти 14%. Sequoia и Lightspeed собираются вложить в размещение ещё денег, а Guardian ждёт один из самых крупных дебютов в истории.

Разбор

Amazon вкладывала миллиарды в Anthropic в 2023 и 2024 годах не только обычными акциями, но и долговыми обязательствами (promissory notes), которые можно обменять на акции. 04Через Optimizely на сайты BBC, CNN и Zoom подсунули вредонос

arstechnica.com4 источникаприменяюттакже: Krebs on Security, The Record, The Register

Почему важноЗначит, сторонний скрипт на сайте — это вход для атаки: код вендора выполняется у каждого посетителя, даже если сам сайт не взломан.

Взломщики положили вредоносный JavaScript на сайты, которые работают через платформу Optimizely для тестов, и нашли его на 178 популярных сайтах, среди них BBC, CNN, Zoom, HSBC и GitLab. Скрипт тянул на компьютеры и телефоны посетителей скиммер, стилер криптокошельков и эксплойты для iPhone. Optimizely подтвердила, что вредоносный код попал в сайты клиентов.

Разбор

Optimizely — сервис A/B-тестов и персонализации, который встраивает свой JavaScript на страницы клиентов, и этот код исполняется на каждой такой странице. Поэтому подмена одного скрипта дала выход сразу на сотни сайтов. Как взломщики вписали свой код в скрипты клиентов, неизвестно: по словам ReportURI, это предстоит объяснить самой Optimizely.

  1. Скрипт был подписан сертификатом Optimizely и шёл с cdn.optimizely.com, то есть через её собственную инфраструктуру. Это не отравление кеша CDN (сети раздачи файлов), а вредный код, доставленный по законному каналу.
  2. Криптокошельки: скрипт ищет адреса девяти криптовалют и подменяет их на адреса взломщиков; по словам ReportURI, деньги у части людей уже украдены.
  3. Карты: скрипт ловит номер, срок и CVV (трёхзначный код на обороте карты), когда все три есть, и шлёт их на 1688360.cc. Платёжные формы Stripe и Adyen во встроенных iframe (вложенных рамках) не затронуты.
  4. Куки и скриншоты: при подмене адреса рядом со словами о кошельке или оплате скрипт отправляет на 1688360.cc куки страницы, исходный адрес и скриншот.
  5. Для iPhone и iPad: DarkSword бьёт iOS 18.x, Coruna — iOS 13–17; отдельная цепочка для iOS 26 только снимает отпечаток устройства и, судя по всему, больше ничего не делает.

Индикаторы компрометации (IOC, признаки взлома: домены, файлы) есть в постах ReportURI и Cynet; ссылок в тексте первоисточника нет.

ОграниченияСписок из 178 сайтов, возможно, не полный. Неизвестно, насколько успешно цепочки эксплойтов ставили полезную нагрузку. В первоисточнике Optimizely на вопросы не ответила, подтверждения от компании там нет.

05В OpenJDK нашли Java4Shell: бьёт по Jenkins, Jira и Confluence

bleepingcomputer.com4 источникаHN 593 ▲ · 153 комм.доступнотакже: Hacker News, The Hacker News, Techmeme

Почему важноЗначит, Jenkins, Jira или Confluence на непропатченной Java открыты для чужого кода даже без логина.

Уязвимость в обработке Base64 позволяет неаутентифицированному атакующему выполнить код на сервере, а под удар попадают Jenkins, Jira, Confluence и Keycloak. Oracle выпустила патч на 11 дыр в Java SE, а компания Calif нашла баг с помощью GPT-6 Cyber.

Разбор

Base64 — способ записать двоичные данные обычными символами, и декодер Java для него используется почти везде, где данные идут через аутентификацию, загрузку файлов и сеть. Поскольку одна и та же Java-среда стоит под многими приложениями, один баг в ней бьёт сразу по разным продуктам. Нашёл его исследователь Куанг Луонг с помощью Codex от OpenAI, AI-ассистента для кода.

  1. Баг в аппаратно ускоренном декодере Base64 на x86-64 процессорах с AVX-512 (наборе векторных инструкций): память портится, и из неё можно вытащить данные или выполнить код.
  2. Луонг нашёл баг примерно за час, рабочий эксплойт сделал ещё за два часа; весь расход на ИИ, по словам Calif, меньше $200. ИИ⁠-⁠агенты потом помогли с цепочками под конкретные приложения.
  3. Без логина RCE в Keycloak, Jira, Confluence, JFrog Artifactory, Jenkins и PingFederate; после логина — в Kafka Broker, Solr, Elasticsearch, Gerrit и Spinnaker. Универсального эксплойта нет: нужен свой способ доставить вредные Base64-данные в конкретное приложение.
  4. Обходы временные: запуск OpenJDK с -XX:-UseBASE64Intrinsics или -XX:UseAVX=2 (отключает AVX-512). Oracle выпустила патчи 17 ноября в ноябрьском Critical Patch Update, где закрыто 655 уязвимостей по всему портфелю.

Calif опубликовала proof-of-concept, показывающий порчу памяти; ссылки в тексте нет, боевые эксплойты публиковать не стали.

ОграниченияТолько x86-64 процессоры с AVX-512 VBMI. Затронуты OpenJDK 17.0.6 и новее, а также Oracle Java SE, Amazon Corretto, Eclipse Temurin, Microsoft Build of OpenJDK, Azul Zulu и Red Hat OpenJDK. Обходы временные, всем разработчикам нужно обновить Java.

Google пишет, что группировки всё чаще используют многоагентные фреймворки вроде Artex, CAIRN, CyberStrikeAI и PentAGI, которые сами ведут многоэтапные взломы. Китайская госгруппа, по данным Google, разрабатывает автоматический инструмент для кибершпионажа.

Google в отчёте AI Threat Tracker пишет, что группы всё чаще запускают не просто чат с моделью, а ИИ⁠-⁠агентов, которые сами проводят многоэтапную атаку. Главное — скорость: модели быстро разбирают патчи и ищут в них баги, поэтому между выходом исправления и атакой остаётся всё меньше времени.

07Claude Code: передай MCP-токен через stdin, и он не попадёт в командную строку

github.com

Почему важноТокены остаются вне командной строки, потому что JSON сервера читается со стандартного ввода.

Запусти команду в обычном терминале, а не внутри открытой сессии Claude Code, там её нет. Вместо <name> подставь имя сервера и передай JSON с токеном на вход: дефис в конце означает чтение со стдина.

Команда или промпт
claude mcp add-json <name> -
Разбор

MCP (Model Context Protocol) — способ подключать к агенту внешние сервисы, у которых обычно есть токен доступа. Токен, переданный в аргументах команды, виден в истории терминала, поэтому его лучше подавать через stdin (стандартный ввод).

  1. Открой обычный терминал, а не сессию Claude Code: в ней эта команда недоступна.
  2. Запусти claude mcp add-json <name> -, вместо <name> подставив имя сервера.
  3. Дефис в конце означает, что JSON сервера с токеном читается со стдина: вставь в ввод JSON с токеном.
Терминал
claude mcp add-json <name> -

Нужна версия Claude Code v2.1.327 (релиз от 17 ноября).

ОграниченияНе работает внутри открытой сессии Claude Code, только в обычном терминале.

08Песочницы для агентов, которые пишут код: выносим выполнение наружу

Почему важноЗначит, агенту с доступом к файлам лучше давать отдельную песочницу, а не твой рабочий комп.

Саймон Уиллисон вместе с командой Prime Radiant разбирает внешние песочницы для кода, который запускают агенты. Идея в том, чтобы безопаснее пробовать локальные модели и не бояться, что ошибка или prompt injection заставят их навредить машине.

Разбор

Схема такая: сам агент остаётся снаружи, а код, который он пишет и запускает, выполняется в отдельной песочнице. prompt injection — это когда в тексте, который читает агент (файл, страница), спрятана чужая команда, и модель её выполняет.

  1. Три реализации: external-sandbox-v86 — сервер на Node.js, который запускает Alpine Linux внутри WebAssembly (байткод, который исполняет браузер).
  2. external-sandbox-container — Python-сервер, Alpine Linux в Apple Containers; external-sandbox-quicksand — Python-сервер на библиотеке Microsoft Quicksand, которая упаковывает QEMU (эмулятор машин) и Alpine Linux в Python-пакет.
  3. Все три дают один и тот же localhost-API: Pi, Claude Code или Codex шлют запросы на выполнение кода в песочницу.
  4. Песочница может включать HTTP/HTTPS-прокси с allow-list (списком разрешённых адресов): можно задать, с какими хостами код агента может общаться.
  5. Замена учётных данных: API вызывается с авторизацией, но секрет остаётся вне агента.

Три сервера: external-sandbox-v86, external-sandbox-container, external-sandbox-quicksand; ссылок в тексте нет, ищи по названиям.
