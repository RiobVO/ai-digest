01Anthropic провела IPO: акции по $83, сбор $81,3 млрд

anthropic.com9 источниковHN 108 ▲ · 58 комм.доступнотакже: Hacker News, TechCrunch, Financial Times, PBS и ещё 4

Почему важноЗначит, у Anthropic теперь публичные акции, и её оценку будут определять биржевые котировки, а не закрытые раунды.

Anthropic разместила акции по $83 за штуку, оценка компании вышла около $1,5 трлн. По FT, собранные $81,3 млрд делают это самым крупным публичным размещением, обогнав SpaceX.

Разбор

Anthropic — компания, которая делает Claude. Теперь её акции начнут торговаться на бирже, и обычные инвесторы смогут их купить через брокера. Контакты для проспекта — Goldman Sachs и Morgan Stanley.

  2. Торги начнутся 19 ноября 2026 на Nasdaq под тикером ANT, сделка закроется 20 ноября.

02Google выпустила Gemini 4 Neon для кода, работы и науки

blog.google4 источникаHN 518 ▲ · 471 комм.доступнотакже: Hacker News, Techmeme, The Decoder

Почему важноЗначит, по выходным токенам счёт на Neon вырастет по сравнению с прошлыми Gemini 4, так что стоимость стоит прикинуть до переезда.

Модель понимает текст, картинки, видео, аудио и PDF, контекст у неё до 1 млн токенов. Стоит $3 за миллион входных токенов и $15 за миллион выходных, это дороже прошлых Gemini 4.

Разбор

Gemini 4 Neon — следующий шаг в линейке Gemini 4 после модели Carbon, с которой Google сравнивает Neon почти в каждом пункте. Главный аргумент Google — цена одной задачи, а не только качество ответов.

  1. В Artificial Analysis Intelligence Index Neon набрала 61 балл на уровне xhigh и заняла #3 в общем зачёте; в Coding Agent Index от того же Artificial Analysis — первое место с 58,6.
  2. На уровне high цена одной задачи на 32% ниже, чем у Carbon; по словам Google, это примерно на 50–80% дешевле топовых конкурентов.
  3. Кешированные входные токены (повторно используемая часть запроса) стоят $0,15 за миллион вместо $3 — скидка 95%.
  4. Кибер-версия по AutoBaxBench пишет более безопасный код, чем Carbon, на всех уровнях задач; на сложном уровне — 76%.
  5. В Collinear CWE-bench v2, где модель чинит уязвимости, Neon набрала 70,7% — на 3,4% больше Carbon.

Через Gemini API в Google AI Studio. Подписчикам Google AI Pro и Ultra — в Google Antigravity, подписчикам Pro и Ultra — в приложении Gemini.

ОграниченияAntigravity доступен только платным подписчикам AI Pro и Ultra. Кибер-версия выходит для доверенных защитников в ближайшие дни через программу Fairwind.

04В nginx нашли десятилетнюю дыру: без входа можно выполнить код на сервере

thehackernews.com4 источникаHN 1176 ▲ · 525 комм.доступнотакже: Hacker News, Хабр · ИБ, The Register

Почему важноЗначит, все версии от 1.9.5 до 1.31.8 с включённым HTTP/2 надо обновлять до 1.31.9 или 1.30.7, ведь по записи nginx работает на 225 млн сайтов.

Ошибка в обработке HTTP/2 позволяет неавторизованному атакующему запустить код на сервере с включённым HTTP/2, логин не нужен. Она сидит в коде с версии 1.9.5 (2015 год), исправления вышли в 1.31.9 и 1.30.7.

Разбор

Баг сидит в поддержке HTTP/2 — современного протокола, по которому браузеры общаются с сайтами. Исследователи из Wiz и Xint уже запустили через него код, а PoC лежит на GitHub, поэтому тема горячая, хотя реальных атак пока не зафиксировали.

  1. На каналах медленнее примерно 300 Мбит/с передача не уложится в часовой лимит соединения по умолчанию, и атака сорвётся.
  2. Для получения root нужен второй баг в SCTP-коде ядра Linux (SCTP — транспортный протокол вроде TCP); в тестах Xint он сработал даже внутри Docker-контейнера.
  3. Все пять уязвимостей в релизе получили оценку CVSS 4.0 9,2 из 10; для NGINX Plus R34–R36 исправления не указаны.
  4. На момент публикации Ubuntu и Debian ещё не выпустили пакеты с исправлением.

Проверить сервер можно openssl-тестом из текста с параметром -alpn h2: если в ответе есть строка ALPN protocol: h2, сервер принимает HTTP/2. За CDN проверяй сам origin-сервер NGINX.

ОграниченияОтключение HTTP/2 закрывает только две из пяти уязвимостей; обходные меры вендор дал лишь для двух. После обновления недостаточно перезагрузить конфиг: нужен полный перезапуск или live binary upgrade.

Взломщики опубликовали на PyPI две вредоносные версии Agent Framework, официального Python-пакета Microsoft для ИИ⁠-⁠агентов. Их задача — красть облачные учётные данные и другую информацию. The Register пишет, что, похоже, скомпрометированы админские доступы к GitHub-организации.

стилер
программа, которая тихо собирает пароли, токены и ключи и отправляет их атакующему.
Разбор

Взломщики не трогали сам Microsoft, а подменили пакет в PyPI — основном каталоге Python-библиотек, откуда разработчики ставят пакеты через pip. Такая атака на цепочку поставок бьёт по тем, кто доверяет официальному имени пакета.

  1. Вредоносные версии 1.26.1 и 1.26.2 опубликовали 17 ноября 2026; пакет скачивают примерно 200 000 раз в месяц.

  4. Данные уходили на webhook.site; крали токены Azure, AWS, GitHub, Docker, Hugging Face, OpenAI и другие.
  5. Как взломщики получили право публикации, неизвестно; в Microsoft запрос отправили, ответа в статье нет.

Проверь, нет ли у тебя версий 1.26.1 или 1.26.2; безопасная версия — 1.26.0.

ОграниченияТем, кто ставил вредоносные версии, рекомендуют изолировать окружение, не запускать Python и pip до очистки, пересобрать его из чистого состояния и сменить все доступные креды.

Почему важноЗначит, открытая веб⁠-⁠панель стала первым шагом к внутренним серверам, и публичные страницы тоже надо считать точкой входа.

В RIKEN сообщили, что Fugaku отключили из⁠-⁠за кибератаки. Взломщики зашли через публичную веб⁠-⁠панель с данными о работе суперкомпьютера, затем попали на внутренние серверы и развернули там малварь. Под угрозой данные более 4500 пользователей, украденные ключи уже пробовали использовать.

07В хуках mcp_tool ставим onFailure: block — если хук упал, действие блокируется

github.com

Почему важноЕсли вызов хука mcp_tool падает, действие теперь блокируется, как уже работает для command и HTTP-хуков.

Открой settings.json, найди в блоке hooks хук типа mcp_tool и добавь в него поле onFailure со значением block. Теперь при ошибке вызова хука действие остановится.

Команда или промпт
"onFailure": "block"
Разбор

В Claude Code хуки — это действия, которые запускаются при вызове инструментов. Поле onFailure уже работало для command и HTTP-хуков, а теперь его можно задать и для mcp_tool. Приём нужен, если хук служит проверкой перед действием и при его падении действие не должно пройти.

  1. Открой settings.json, в котором настраиваются хуки Claude Code.
  2. В блоке hooks найди хук типа mcp_tool.
  3. Добавь в этот хук поле onFailure со значением block.
  4. Проверка: теперь при ошибке вызова хука действие остановится.

Нужна версия Claude Code v2.1.328 — изменение добавлено в ней; релиз опубликован на GitHub 19 ноября.

ОграниченияВ тексте нет примера JSON и не сказано, где именно лежит settings.json на твоей машине.

Почему важноЗначит, у большого открытого проекта уже есть опыт, когда агенты дают не только переписанный код, но и реальные багфиксы.

Разбор

Цитата опубликована в блоге Саймона Уиллисона 18 ноября 2026.

Харджот Гилл, CEO CodeRabbit, рассказал, что за месяц выпустил больше 5000 пулл-реквестов. Он тратит на ИИ $250 тысяч в месяц и считает, что ручное ревью кода уходит в прошлое.

Разбор

CodeRabbit делает ИИ⁠-⁠ревью кода, так что Харджот Гилл — не просто пользователь ИИ, а CEO компании, которая продаёт такие инструменты. В разговоре с Гергели Оросом из The Pragmatic Engineer он объясняет, почему тратит столько на ИИ.

  1. По оценке Гилла, одна PR обходится компании примерно в $150; расходы на ИИ — $250–275 тысяч в месяц при команде из 40 инженеров.
  2. Поставщик предлагал $13 млн в год за CI-систему; её написали агентами за неделю, и она вышла на 50% дешевле предложения при похожей скорости.
  3. Есть «review exempt list» — разработчики, которые могут пушить в прод без ревью; после аварии виновный получает страйк, и при наборе страйков его релизы идут на ревью.
  4. Дообучать модели перестали: новые фронтирные модели выходят быстрее, и поддерживать собственные дообученные модели не окупается.
